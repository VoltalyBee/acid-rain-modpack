# Acid Rain pour Prism Launcher

1. Dans Prism Launcher, choisis **Ajouter une instance → Importer depuis un ZIP**.
2. Importe **Acid_Rain_Prism_Joueurs.zip**, puis lance **Acid Rain** avec Java 17.
3. Dans **Multijoueur**, rejoins **Acid Rain**.

Cette archive contient déjà les versions fournies d’Advanced Stands et d’Easy NPC Bundle. Tu n’as pas à rechercher ces mods séparément. Les autres mods, shaders et configurations sont récupérés par l’installateur au premier lancement.

Aux lancements suivants, l’installateur vérifie le pack publié par l’administratrice et récupère uniquement les fichiers nécessaires aux changements.

Adresse du pack : https://voltalybee.github.io/acid-rain-modpack/pack.toml
Serveur : acidrainvoltalybee.ouimc.fr

Un compte qui possède Minecraft Java est nécessaire. Cette instance utilise les réglages Java et mémoire de ton Prism Launcher.

Pour l’administratrice : Advanced Stands reste dans sa version actuelle. Une future version de ce mod demandera une source de téléchargement automatique autorisée pour les joueurs déjà installés. Le ZIP n’accorde aucun droit supplémentaire de redistribution des mods.

L’installateur provient du projet officiel https://github.com/packwiz/packwiz-installer-bootstrap ; sa licence est jointe.
