# Acid Rain pour Prism Launcher

Importe ce ZIP dans Prism avec **Ajouter une instance → Importer depuis un ZIP**, puis lance **Acid Rain**. Utilise Java 17 et un compte qui possède Minecraft Java.

La commande avant lancement récupère le pack publié à cette adresse :

https://voltalybee.github.io/acid-rain-modpack/pack.toml

Le premier lancement télécharge les mods, shaders et configurations. Les lancements suivants ne récupèrent que les fichiers nécessaires aux changements du pack.

Dans **Multijoueur**, rejoins **Acid Rain** à l’adresse `acidrainvoltalybee.ouimc.fr`.

Si l’installateur demande un fichier CurseForge manuellement, suis sa fenêtre de téléchargement. Si le lien du pack affiche une erreur, l’administratrice doit terminer la publication GitHub Pages avant le lancement.

L’installateur provient du projet officiel [packwiz-installer-bootstrap](https://github.com/packwiz/packwiz-installer-bootstrap). Sa licence est jointe.
